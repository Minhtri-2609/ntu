# 🌐 Personal Website - NTU

Welcome to the source code repository of **Minh Trí**'s personal website!

This repository contains all the HTML, CSS, and JavaScript source code designed and built for a personal introduction website.

---

## 🚀 Live Demo
You can visit and experience the website at:
🔗 [tlamthat.id.vn](https://tlamthat.id.vn)

---

## 📂 Project Structure
The project includes the following main files:
* `index.html`: The main homepage of the website.
* `login.html`: The account login page.
* `profile.html`: The detailed personal profile page.
* `account.html`: The account management page.
* `*.css` (badges.css, print.css, site-ui.css, style.css...): Stylesheets that define the interface.
* `*.js` (clock.js, site-ui.js): Scripts that handle logic and effects.
