# 🌐 Trang Web Cá Nhân - NTU

Chào mừng bạn đến với kho lưu trữ mã nguồn trang web cá nhân của **Minh Trí**! 

Kho lưu trữ này chứa toàn bộ mã nguồn HTML, CSS và JavaScript được thiết kế và xây dựng để làm trang web giới thiệu thông tin cá nhân.

## 📂 Cấu Trúc Thư Mục Dự Án
Dự án bao gồm các tệp chính sau:
* `index.html`: Trang chủ chính của website.
* `login.html`: Trang đăng nhập tài khoản.
* `profile.html`: Trang hồ sơ cá nhân chi tiết.
* `account.html`: Trang quản lý tài khoản.
* `*.css` (badges.css, print.css, site-ui.css, style.css...): Các tệp định dạng giao diện (CSS).
* `*.js` (clock.js, site-ui.js): Các tệp xử lý logic và hiệu ứng (JavaScript).
